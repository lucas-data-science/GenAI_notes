# IA Generativa para Data Science — Notas de Estudo

Notas de estudo sobre IA Generativa e LLMs aplicadas a Data Science, organizadas em
fases. Cada capítulo é um Jupyter notebook executável, em `contents/<fase>/`.

O conteúdo segue um plano de 13 fases, dos fundamentos de Deep Learning até
observabilidade e deploy de aplicações com LLMs. Este site publica as fases já
concluídas.

## Fases

1. **Fundamentos de Deep Learning** — perceptron, MLP, backpropagation, funções de
   ativação e perda, otimização (SGD, Adam), regularização (L2, Dropout, BatchNorm) e
   introdução a features tabulares.

Demais fases (NLP, RNN/LSTM, Transformers, LLMs, RAG, agentes, MCP, APIs, deploy) serão
adicionadas conforme concluídas.
